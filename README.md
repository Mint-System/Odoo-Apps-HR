# Odoo Apps: Hr

Odoo modules extending the `hr` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Hr.git ./addons/hr
```

## Available modules

| Module | Summary |
| --- | --- |
| [hr_attendance_delta](hr_attendance_delta) |         Calculates timespan between attendance entries. |
| [hr_attendance_policy](hr_attendance_policy) |         Manage and check work time policies on attendance entries. |
| [hr_attendance_user_acl](hr_attendance_user_acl) |           Restrict user access rights to hr attendance entries. |
| [hr_contract_leaves_domain](hr_contract_leaves_domain) |         Adds time_type to expected hours calculation in hr_contract. |
| [hr_employee_attendance_report_balances](hr_employee_attendance_report_balances) |         Adds balances to attendance report. |
| [hr_employee_attendance_report_batch_send](hr_employee_attendance_report_batch_send) |         In the HR view, with a selection of employees, have the action in the topbar to send the attendance report to each employee. |
| [hr_employee_attendance_report_leaves](hr_employee_attendance_report_leaves) |         Adds leave informations to report. |
| [hr_employee_attendance_report](hr_employee_attendance_report) |         Attendance and leave report. |
| [hr_employee_attendance_report_timestamps](hr_employee_attendance_report_timestamps) |         Adds timestamp column to report. |
| [hr_employee_skill](hr_employee_skill) |         Views to manage HR employee skills. |
| [hr_employee_user_acl](hr_employee_user_acl) |         Restrict access to employees app. |
| [hr_expense_user_acl](hr_expense_user_acl) |         Restricted access to expenses app. |
| [hr_holidays_negative_hours](hr_holidays_negative_hours) |         Allow submit time-off request with negative extra hours. |
| [hr_holidays_type_note](hr_holidays_type_note) |         Set note on leave type that is shown on request. |
| [hr_holidays_user_acl](hr_holidays_user_acl) |         Restricted access to time off app. |
| [hr_holidays_working_time](hr_holidays_working_time) |         Generate attendance entries for leaves. |
| [hr_payslip_report_manual_note](hr_payslip_report_manual_note) |         Adds a text Field to the payslip that appears at the bottom of the swiss payslip. |
| [hr_timesheet_attendance_record](hr_timesheet_attendance_record) |         Generate attendance records from timesheet entries. |
| [resource_attendance_time_type](resource_attendance_time_type) |         Adds the option to change the time_type in public holidays and adds 'attendance' as additonal type. |
